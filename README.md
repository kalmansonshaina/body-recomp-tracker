# Body Recomp Tracker

A flexible **body-recomposition tracker** built as an **offline-first PWA** — install it to your
phone's home screen and use it at the gym with no internet. All your data stays on your device
(nothing is sent anywhere, no account needed).

Built as a single, dependency-free vanilla-JS app (no build step) so it can be hosted for free on
GitHub Pages.

## What it does

The program is deliberately **not** tied to fixed weekdays. The goal is consistency and
progression, not a rigid schedule.

- **Body Recomp Score** — one weekly score /100 from the habits that actually drive results
  (strength 40 · Pilates/yoga 20 · steps 15 · cardio 10 · supplements 10 · tracking 5).
- **Four strength workouts** in a rotation (Lower A → Upper A → Lower B → Upper B) that resets
  each week. The app always recommends the next one, but you can pick any.
- **Set/rep/weight logging** with an effort ("reps in the tank") selector, pain flags, notes and
  on-the-fly exercise **substitutions**.
- **Double-progression suggestions** — tells you when to add reps, add weight, hold, or back off,
  per exercise, based on your last session.
- **Pilates / yoga**, **StairMaster / treadmill / walk** cardio, and an optional **ab circuit**.
- **Steps**, **weight** (7-day rolling average + trend chart), and **measurements**
  (with waist-to-hip ratio and per-area change).
- **Supplement tracker** — your own list, a daily checklist, and adherence %.
- **One-minute daily check-in** (energy, sleep, soreness, optional cycle phase).
- **Weekly review** with an encouraging status (Excellent / Solid / Recovery).
- **Progress photos** stored locally on the device.
- **Exercise library** with form cues, target muscles and safe swaps.

## Install on your iPhone

1. Open the hosted URL in **Safari**.
2. Tap the **Share** icon → **Add to Home Screen**.
3. Launch it from the new icon — it opens full-screen and works **offline**.

On Android/Chrome you'll get an **Install** prompt instead.

> **Heads-up on Apple Health:** a web app can't read Apple Health, so **steps are entered
> manually** (one quick tap-in). Everything else works fully offline.

## Your data

Everything lives in this device's browser storage. Use **More → Export backup** regularly —
clearing Safari website data or deleting the app will erase it. You can restore from a backup
file at any time.

## Project structure

| File | Purpose |
|------|---------|
| `index.html` | App shell + iOS install meta tags |
| `styles.css` | Design system (light/dark, iPhone safe-area aware) |
| `app.js` | The whole app — data model, logic, screens, progression engine |
| `manifest.webmanifest` | PWA manifest (installable) |
| `sw.js` | Service worker (offline caching) |
| `icons/` | App icons (generated by `gen_icons.py`) |
| `gen_icons.py` | Regenerates the PNG icons (no dependencies) |
| `smoke.mjs` | Playwright end-to-end smoke test |

## Development

No build step. To preview locally:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

Run the smoke test (needs `playwright-core` + a local Chromium):

```bash
node smoke.mjs
```
